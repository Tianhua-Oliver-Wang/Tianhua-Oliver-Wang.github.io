# 下一步内容准备

优先完成以下内容即可形成可正式使用的个人学术主页，不必一次填满所有栏目。

## 第一批：身份与简介

- 中文姓名、希望使用的英文姓名及姓名顺序。
- 学校、院系、专业、当前学位阶段；中英文官方名称优先。
- 100–200 字中文简介。英文和香港繁体中文版本由我协助撰写，交本人确认。
- 可公开邮箱、GitHub，以及已有的 ORCID / Google Scholar 等链接；没有则不展示。
- 是否提供真实个人照片。没有照片也能维持现有排版。

## 第二批：研究兴趣

- 确认目前列出的三个方向是否准确，删去不代表个人兴趣的问题。
- 如果有具体研究计划，提供研究问题、研究对象、数据来源设想和当前状态。
- 拟议问题与正在进行的项目分开表述。

## 第三批：真实研究与写作

- 论文：完整标题、作者顺序、准确状态、年份及公开链接。
- 项目：标题、本人角色、研究问题、起止时间、实际进展和公开材料。
- 写作：课程论文、阅读笔记或评论，明确各自性质，勿将课程作业表述成正式发表成果。
- 暂无内容的栏目可以继续保留简短说明，或在后续版本中隐藏。

## 第四批：履历

- 教育背景、研究经历和已发生的学术活动。
- 真实 CV PDF；所有语言可先共用英文 CV，按钮文案会随网页语言变化。

## 三语原则

美国英文使用美式拼写；简体中文使用中国内地书面表达；香港繁体中文采用香港书面表达（如基建、電郵、聯絡、投資誘因）。三语描述相同事实，不增加或弱化资历、研究进展和贡献。专有名词以学校、机构或论文官方名称为准。暂时用 GitHub 用户名标识身份，不推测中文姓名。
