# 网站配色基准与姓名微调

颜色采用十六进制 HEX 代码，通常是六位 RGB（#RRGGBB），不是“16 位代码”。以下为当前全部明确指定的颜色；没有渐变、额外阴影色或第三方配色。

此表为当前项目统一配色基准。后续新增栏目、页面及三语版本均复用以下语义变量；调整时同步更新此表与 `assets/style.css`，避免单个页面出现独立色值。维护要求已写入项目 `AGENTS.md`。

## 屏幕配色

| CSS 变量 | 用途 | 浅色模式 | 深色模式 |
| --- | --- | --- | --- |
| `--paper` | 页面背景；实心按钮及选中语言项的文字 | `#F5F8F1` | `#213229` |
| `--ink` | 英文姓名、标题、正文、常规链接及主题图标；实心按钮和选中语言项的背景 | `#224333` | `#E8F0E5` |
| `--name-ink` | 中文姓名及其同色描边 | `#144C30` | `#D5EBD6` |
| `--muted` | 副标题、说明、编号、主题标签、侧栏简介及页脚 | `#536F5E` | `#BBCCBC` |
| `--line` | 分隔线、边框、空状态左侧竖线 | `#D3E0D1` | `#49604F` |
| `--wash` | 研究问题底色、主题按钮悬停背景 | `#E6F0E1` | `#2E4435` |
| `--accent` | 链接悬停、当前导航项、键盘焦点框、实心按钮悬停背景 | `#287247` | `#A8D9AE` |

太阳和月亮图标使用 `currentColor`，即继承当前 `--ink`；中文描边也使用 `currentColor`，继承 `--name-ink`。它们不是额外的固定色。

主题按钮常态背景使用 `transparent`，可表示为八位 HEX `#00000000`，实际透出页面底色；SVG 的 `fill: none` 表示不填充。

## 打印配色

打印背景为 `#FFFFFF`。其余变量固定使用浅色值：正文 `#224333`、中文姓名 `#144C30`、辅助文字 `#536F5E`、分隔线 `#D3E0D1`、问题底色 `#E6F0E1`、强调色 `#287247`。

## 修改位置

打开 `assets/style.css`：

- `:root`：浅色模式。
- `html[data-theme="dark"]`：手动选择的深色模式。
- `@media(prefers-color-scheme:dark)`：未手动选择时的系统深色模式，修改深色值时与上一处同步。
- 文件末尾 `@media print`：打印配色。

所有页面和语言共用此文件。保存后刷新本地预览；上传更新后的 CSS 才会改变线上页面。

## 中文姓名的当前微调
