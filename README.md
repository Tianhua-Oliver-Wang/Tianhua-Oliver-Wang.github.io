# 三语个人学术主页

延续原有米白与深绿配色，采用内容优先的布局。桌面端是目录侧栏与正文，较窄屏幕上目录移至正文上方。所有网页都是静态 HTML；内容和语言切换无需 JavaScript。深色模式按钮使用本地 JavaScript，不依赖在线翻译或第三方字体。

## 页面结构

每种语言都有首页、研究方向、写作与笔记、个人履历四页，共十二页。

| 语言 | 首页 | 语言规范 |
| --- | --- | --- |
| 英文（默认） | `index.html` | `en-US`，美国英文 |
| 简体中文 | `zh-cn/index.html` | `zh-CN`，中国简体中文 |
| 繁體中文 | `zh-hk/index.html` | `zh-HK`，香港繁體中文 |

语言切换进入对应语言的同类页面，例如英文研究页切换繁体中文后仍在研究页。首次从默认英文入口进入时，按设备的首选语言自动选择：简体中文使用简体版，香港／台湾／澳门或 Hant 繁体中文使用香港繁体版，其他语言使用英文。手动选择会保存在浏览器中，之后优先使用该选择。直接打开简体或繁体网址时保留对应语言。每页有正确的 HTML 语言标记及对应页面的 canonical / hreflang 信息。

内容参考 https://gwagner.com/ 的分类思路：个人身份与履历、研究内容、对外写作分别组织；成果可附作者、日期、状态、摘要、主题及链接。不使用参考网站的文章、图像、资历或经历。研究页的问题是拟议研究方向示例，已明确标注，需本人确认后再作为正式研究介绍。

## 这一次怎样更新 GitHub

网站仍发布在你的原有仓库，不需要新建仓库或重新设置 Pages。

1. 解压 `academic-homepage-multilingual.zip`。
2. 打开仓库，选择 **Add file → Upload files**。
3. 在 Finder 中进入解压后的文件夹，选中**里面所有可见文件和文件夹**，一起拖入上传框（不要拖最外层文件夹，也不要上传 ZIP）。
4. 提交前确认列表中同时有根目录的 `index.html`、`research.html`、`writing.html`、`cv.html`，以及 `assets/style.css`、`zh-cn/`、`zh-hk/` 中的网页。
5. 点击 **Commit changes**，更新现有 `index.html` 并新增其他文件。Pages 会使用之前设置的 `main` 和 `/(root)` 发布。
6. 部署结束后检查英文、简体、繁体入口及语言切换。

## 内容维护

推荐编辑 `content/site.json`，它集中存放三个语言版本的文案，然后在此文件夹运行：

```bash
python3 build.py
```

Python 只负责生成网页，不参与线上运行；无第三方依赖。生成后提交修改后的源文件和 HTML。没有 Terminal 也可直接在 GitHub 编辑对应 HTML；但之后运行生成器会覆盖直接编辑的 HTML，因此长期建议维护 JSON，由我协助生成。

- `profile.github`：GitHub 主页。
- `profile.email`：公开邮箱；空字符串表示暂不展示。
- `profile.cv_file`：真实 CV 相对路径，如 `assets/cv.pdf`；为空时不产生下载链接。添加前把文件放到该路径。
- `locales`：三套独立文案。`name` 为该语言的公开姓名，当前使用已确认的 Tianhua Oliver Wang。
- `about`：简介段落列表。确认真实个人信息后，可清空 `bio_pending`。
- `areas`：研究主题、简述、潜在研究问题、主题词。
- `publications`、`projects`、`writing`：目前为空列表。新增真实条目时，每个条目可使用下列字段：

```json
{
  "title": "真实条目标题",
  "authors": "真实作者信息（可选）",
  "date": "2026-10-25",
  "status": "准确的发表或项目状态（可选）",
  "summary": "简述",
  "tags": ["主题"],
  "url": "https://实际公开链接"
}
```

以上只是格式说明，未写入网页成果列表。按希望展示的先后顺序添加条目，不自动排序。三个语言版本分别维护；没有正式中文译名的论文，标题可保留英文。日期建议使用 `YYYY-MM-DD`，避免地区格式歧义。主题词是内容标签，目前不带筛选功能。

目前个人履历页只包含待填写栏目。补充真实教育及经历后，可直接修改生成器对应结构，或由我继续完善数据格式；不会自动生成学历或经历。

## 中文姓名手写字体

中文名使用霞鹜文楷 TC 的姓名专用子集（王、天、华、華，约 3 KB），字体随站点托管，不在访问时请求 Google Fonts。来源：https://github.com/lxgw/LxgwWenkaiTC ，遵循 SIL OFL 1.1；许可文件随字体保存在 `assets/fonts/`。

`assets/name-alignment.js` 在字体加载后测量可见字形边缘，将中文名上缘对齐英文大写 T 的上缘、下缘对齐英文姓名的最下缘（含 Wang 中 g 的下伸部分），并在窗口尺寸改变时重新计算。没有 JavaScript 时使用 CSS 基线对齐作为回退。如改名涉及其他汉字，需要更新当前只含四个字的字体子集。

## 英文大小写规范（长期适用）

英文标题、导航、按钮、行动链接与主题标签统一采用美式 Title Case，例如 Finance for a Changing Climate.、Writing & Notes、Explore Research Interests、View Curriculum Vitae。标题中的冠词、并列连词和短介词（如 a、and、for、of、to）通常保持小写；正文仍用正常句式。规则已写入项目 `AGENTS.md`，后续新增页面沿用。论文的正式标题和引用信息按原文保留，不自动改写。

中文姓名视觉微调：保留文楷手写体，以 `0.016em` 同色描边轻微增加笔画分量；在字形测量对齐基础上，再向上移动 `0.06em`（桌面约 2 像素），使视觉中心更贴近英文。尺寸变化时两项均按字号缩放，深浅主题沿用文字颜色。

当前全站 HEX 配色表与姓名微调参数见 `docs/COLORS.md`；该表包含浅色、深色、打印及透明背景说明。中文姓名现以 `.022em` 同色描边加粗，在原有上移基础上再上移 `1px`，浅色下独立采用深绿 `#193D2B`。

简繁中文姓名现在共用 `王天华華` 四字的测量范围，英文姓名统一使用相同字体栈，避免简繁切换导致字号和垂直位置变化。480px 以下页首姓名采用更小的流动字号；空间不足时语言和主题工具独立换行。当前配色以 `docs/COLORS.md` 为准。
